Step 1: Run the following command in your codespace terminal to create a utmp file.

sudo touch /var/run/utmp

Step 2: The following command will mimic a utmp entry.

sudo bash -c "echo '[1] [00049] [~~  ] [runlevel] [~           ] [4.4.0-17115-Micoroso] [0.0.0.0        ] [Wed Feb 28 13:27:14 2018 STD]' | utmpdump -r > /var/run/utmp"


Step 3: Simulates a user login

sudo login -f $USER


Step 4: run who

who



Step 5: Now you can execute your own C program which mimics the who command. 

gcc my_who.c
./a.out



Step 6: Once you are done working with your C program, you can logout from the current terminal session that you started in Step 3.

logout
